表の読み方

列意味
CLItesla-control のコマンドと位置引数。角括弧はオプション引数。「—」は CLI コマンドがないことを示します
Go(*vehicle.Vehicle) のメソッド。第 1 引数の ctx は省略
プロキシPOST /api/1/vehicles/{VIN}/command/<名前> の <名前> と JSON ボディのキー。pkg/proxy/command.go 基準。「—」はプロキシのエンドポイントがないことを示します（REST にも転送されず invalid_command）
ドメインVCSEC セキュリティコントローラー。Infotainment がスリープ中でも BLE で応答します。INFO Infotainment。スリープ中は先に起こす必要があります
認証必要 秘密鍵とセッションが必要（requiresAuth）。不要 セッションなしで送信可能
備考BLE 専用、Fleet API 専用、車種の制限など
ロールによる制限

同じコマンドでも、キーのロールによっては拒否されることがあります（MESSAGEFAULT_ERROR_INSUFFICIENT_PRIVILEGES）。例：Driver はキー管理と PIN 変更ができず、Vehicle Monitor は状態の取得のみ、Charging Manager は充電関連のみ、Fleet Manager は 2023.38 以降で BLE コマンドと他のキーの追加/削除ができません。ロールの詳しい説明は 4. プロトコル仕様 を参照してください。

プロキシが REST に転送するエンドポイント

次の command/ エンドポイントはサーバー側の処理が必要なため、エンドツーエンド認証では実装できません。プロキシは ErrCommandUseRESTAPI を受け取ると、元のリクエストをそのまま Fleet API に転送します。

  • navigation_request
  • set_managed_charge_current_request
  • set_managed_charger_location
  • set_managed_scheduled_charging_time

command/ 以外のすべてのパス（vehicle_data、wake_up 以外の取得エンドポイントなど）は常にフォワーディングされます。車両がこのプロトコルをサポートしておらず Fleet API が 422 を返した場合、その VIN は以後常にフォワーディングされます（8. HTTP プロキシ）。
