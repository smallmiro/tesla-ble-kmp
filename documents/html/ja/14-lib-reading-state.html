14. 車両状態の取得

3 つのクエリが BLE で車両のセキュリティコントローラー (VCSEC) を読み取ります。インフォテインメントコンピューターがスリープしていても VCSEC は応答するため、キー、セッション、ウェイクアップはいずれも不要です。

  2. vehicleStatus() の戻り値
  3. キークエリの戻り値
  4. 接続とセッションの状態
  5. スリープとウェイクアップ

3 つのクエリ

呼び出し戻り値Go 原本
vehicleStatus()ロック、ドア、トランク、充電ポート、スリープ状態、在車状態BodyControllerState
keySummary()登録済みキーの数と使用中のスロットKeySummary
listKeys()登録済みのすべてのキーと、その公開鍵、ロール、フォームファクターKeySummary + KeyInfoBySlot
  • いずれも省略可能な timeout を受け取ります。指定しない場合はデフォルトのコマンドタイムアウト (5 秒) が適用されます。listKeys() では、このタイムアウトがすべてのリクエストの合計にかかります。
  • 車両は接続ごとに VCSEC リクエストを 1 つずつ処理します。別のクエリを待つ必要があるクエリは、タイムアウトの一部を待ち時間に使います。
  • これらはクエリなので、Uncertain の結果はそのまま再度問い合わせて構いません。

vehicleStatus() の戻り値

フィールド値
lockStateUNLOCKED, LOCKED, INTERNAL_LOCKED, SELECTIVE_UNLOCKED, UNKNOWN
closures8 つの開口部で、それぞれ ClosureState です。車両が送ってこなかった場合は null
sleepStatusAWAKE, ASLEEP, UNKNOWN
userPresencePRESENT, NOT_PRESENT, UNKNOWN
tonneauPercentOpenCybertruck のみ。それ以外は null

8 つの開口部は frontDriverDoor、frontPassengerDoor、rearDriverDoor、rearPassengerDoor、rearTrunk、frontTrunk、chargePort、tonneau です。それぞれ CLOSED、OPEN、AJAR、OPENING、CLOSING、FAILED_UNLATCH、UNKNOWN のいずれかです。

未知の値でも失敗しません

新しい車両ファームウェアがライブラリの知らない値を送ってきた場合、クエリを失敗させずに、そのフィールドは UNKNOWN になります。

キークエリの戻り値

型フィールド意味
WhitelistSummarynumberOfEntries登録されているキーの数
slotMask, occupiedSlots使用中のスロット。ビットマスクとソート済みリストの両方
WhitelistEntryslotスロット番号
publicKey65 バイトの公開鍵。欠落または不正な場合は null
keyIdSha1Hex公開鍵の SHA-1 (16 進数)、または null
role, formFactor例えば OWNER と IOS_DEVICE。13. キーとペアリング を参照してください

接続とセッションの状態

これらは車両に送る問い合わせではなく、監視する Vehicle のプロパティです:

プロパティ値
connectionConnected、または Disconnected (わかる場合はその理由付き)
sessionsVCSEC と INFOTAINMENT それぞれについて None、Handshaking、Ready (fromCache 付き)
hasKeyキーを使って接続したかどうか
vinVIN です。出力するとマスクされた形式になります。vin.value は生の VIN なので、ログに出さないでください

スリープとウェイクアップ

  • 3 つのクエリはいずれも車両をウェイクアップしません。スリープ中かどうかの表示には sleepStatus を使います。
  • M5 で追加予定: getState(category) は 12 のインフォテインメントカテゴリ (充電、空調、走行、位置、開閉部、充電スケジュール、プレコンディショニングスケジュール、タイヤ空気圧、メディア、メディア詳細、ソフトウェアアップデート、ペアレンタルコントロール) を読み取ります。登録済みキーと起きている車両が必要です。
  • M4 で追加予定: wakeUp()。VCSEC セッションだけで使えます。
  • ロックやトランクのコマンド (M4) が Uncertain を返した場合は、コマンドを再送せずに vehicleStatus() をもう一度読み取ってください。
