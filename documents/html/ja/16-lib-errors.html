16. エラー処理

すべての呼び出しは 3 つの結果のいずれかを返し、すべてのエラーは車両が動作した可能性があるか、もう一度試せば解決しうるかを示します。ライブラリは安全にリトライできるものをすでにリトライしているため、ほとんどのアプリは結果で分岐するだけで済みます。

3 つの結果

結果意味アプリがすること
成功車両が確認した値を使います
不確実車両が実行した可能性があるが、確認が届かなかった再送 しないでください。代わりに状態を読み取ります (vehicleStatus()、M5 以降は getState())
失敗実行されなかったerror を確認します

Swift では switch onEnum(of: result) で .success、.uncertain、.failure を網羅します。12. ライブラリ入門 を参照してください。自分のコルーチンや Task のキャンセルは結果に変換されず、通常どおりキャンセルが伝播します。

エラーの種類

すべての VehicleError は message (英語)、mayHaveSucceeded、temporary を持ちます。shouldRetry() は、エラーが一時的で、かつ車両が動作した可能性がない場合に true です。ライブラリはそれらをすでにリトライしているため、リトライループは不要です。

型発生する場面一時的成功した可能性
ProtocolFault車両がプロトコルのフォールトコードを送ったbusy、timeout、署名、カウンター、内部、エポック、有効期限のフォールトのみNONE と RESPONSE_MTU_EXCEEDED のみ
KeyNotPaired車両がこのキーを知らないいいえいいえ
Busy車両が待つよう求めたはいいいえ
UnknownFault, UnknownKeychainCode, UnknownResponse新しいファームウェアがこのライブラリの知らないコードを送った。アップデートを確認してくださいいいえいいえ
NotConnected, NoSession, RequiresKey呼び出し順が誤っているか、キーなしで呼び出したいいえいいえ
BadResponse応答を読み取れなかったいいえVCSEC と Infotainment の応答でははい
KeychainRejected, VcsecRejected, InfotainmentRejected車両は理解したが拒否したいいえいいえ
TransportErrorBluetooth のスキャン、接続、書き込みスキャンのタイムアウト、接続失敗、書き込み失敗のみいいえ
KeyStoreErrorプラットフォームのキーストアいいえいいえ
Timeoutコマンドが時間切れになったはいすでに送信済みだった場合
InvalidArgument不正な引数いいえいいえ

各プロトコルフォールトコードの意味は 9. エラーとトラブルシューティング にあります。

Bluetooth とキーストアのエラー

接続は接続タイムアウトまで 1 秒ごとにすでにリトライされます。最後の列はアプリがすべきことです。

エラー意味対処
ScanTimeout時間内に車両が見つからなかった車両が範囲内にあるか確認し、もう一度試します
MaxConnectionsExceeded車両にすでに 3 つの Bluetooth 接続がある別のスマートフォンやアプリを切断し、もう一度試します
ConnectFailed接続、サービスの検出、または購読に失敗した少し待ってからもう一度試します
Disconnectedリンクが切れたdisconnect() を呼んでから再接続します
BluetoothOffBluetooth がオフオンにするようユーザーに依頼します
PermissionDeniedBluetooth の権限がない権限を要求するか、設定を開きます
WriteFailed送信に失敗した自動でリトライされます。繰り返し起きる場合は再接続します
HardwareUnavailableハードウェアが必須だが使えないPREFER_HARDWARE を使います
KeyNotFoundそのエイリアスのキーがないgetOrCreate で作成します
PlatformFailureプラットフォームのキーストアが失敗した。stored key is corrupted は保存されたキーが破損していることを示す破損したキーは自動で置き換えられません。削除して作成し、新しいキーを再度登録します

リトライとタイムアウト

ライブラリは Go の原本と同じルールでリトライします。

状況ライブラリの動作
車両が動作した可能性のない一時的なエラー (busy、待機、期限切れ、不正なカウンター…)1 秒待ち、新しいカウンターと有効期限でコマンドに署名し直して再送します。エラーと一緒に届いたセッション情報を先に適用します
車両が動作した可能性のあるエラー (応答なし、読み取れない応答)トグルが 2 回実行されないよう、決して再送しません。Uncertain を返します
送信前に時間切れになったFailure(Timeout)
応答を待つ間に時間切れになったUncertain(Timeout)
ハンドシェイクが時間切れになったFailure(Timeout)。セッションは作られず、何も変わっていません
TeslaBleConfigデフォルト用途
