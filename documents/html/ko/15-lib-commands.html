15. 명령

현재 Vehicle은 세션을 시작하고 끝낼 수 있습니다. 제어 명령은 M4(보안 컨트롤러: 잠금, 트렁크, 깨우기)와 M5(인포테인먼트: 공조, 충전, 미디어 등)에서 추가됩니다. 앱을 계획할 수 있도록 이 페이지에 둘 다 정리합니다.

현재 사용 가능

호출동작
startSession(domains, timeout)VCSEC와 Infotainment(기본값은 둘 다)의 핸드셰이크를 병렬로 실행합니다. 세션 캐시에서 이미 복원된 도메인은 차량에 묻지 않고 성공합니다. 등록된 키가 필요합니다. 기본 시간 제한 20초
disconnect()세션 캐시를 저장하고, 세션 키를 지우고, 링크를 닫습니다. 여러 번 호출해도 안전합니다

startSession이 실행되는 동안 vehicle.sessions는 Handshaking을 보여 주고, 끝나면 Ready, 실패하거나 취소되면 다시 None이 됩니다.

모든 명령의 공통 동작

명령 아래의 기반 구조는 이미 갖춰져 있으므로 다음 규칙은 확정되어 있습니다.

  • 명령은 도메인 세션 위에서 AES-GCM으로 암호화, 인증되며 5초 후 만료됩니다.
  • 일시적 실패는 1초마다 자동으로 재시도합니다. 이미 실행되었을 수 있는 명령은 절대 다시 보내지 않습니다.
  • 보안 컨트롤러 명령은 연결마다 한 번에 하나씩 실행되고, 인포테인먼트 명령은 동시에 실행될 수 있습니다.
  • Uncertain 결과는 상태를 읽고 재전송하지 말라는 뜻입니다. 16. 에러 처리를 참고하세요.
