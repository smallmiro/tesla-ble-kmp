11. ライブラリ概要

tesla-ble-kmp はこのリポジトリで作っているライブラリです。vehicle-command の BLE 経路を Kotlin Multiplatform に移植したもので、Android や iOS のアプリがサーバーなしでテスラと直接通信できるようにします。第 11 章から第 19 章ではその使い方を、第 1 章から第 9 章では Go の原本を説明します。

設定と全 API を一つのオフラインファイルで読むには、統合利用ガイドを開いてください。パラメーター表、呼び出し例、戻り値、クラス、12種類の状態スキーマを収録し、API 検索と印刷に対応しています。

予定の API はまだ使えません

予定のメソッド名は要件ドキュメント (docs/prd/PRD.md) に基づいており、マイルストーンの実装時に変わる可能性があります。現在、アプリはスキャン、接続、状態の読み取り、getState() によるインフォテインメント状態の読み取り、車両のブロードキャストの受信、キーの登録、ロック中もキーを使うかどうかの選択、VCSEC 制御コマンドとすべてのインフォテインメントコマンドの送信ができます。ペアリング、VCSEC コマンド、getState()、インフォテインメントのコマンドは実車ではまだ確認していません。

プラットフォームとパッケージ

  • Android 12 (API 31) 以降と iOS 16 以降に対応します。アプリはフォアグラウンドにあることを前提とします。
  • テストや実験用に JVM ターゲットもあります。そのキーとセッションキャッシュはメモリ上にのみ保持されます。
  • パッケージのルートは dev.mirolab.teslable です。ファサードは dev.mirolab.teslable、値と結果は dev.mirolab.teslable.model、キーストア、スキャン、ログは dev.mirolab.teslable.port にあります。Wire が生成したプロトコルの型は com.tesla.generated.* にあります。例: com.tesla.generated.carserver.vehicle.VehicleData。
  • iOS フレームワーク名は Teslable です。Swift からは SKIE を通して Kotlin が見えます (async 関数、AsyncSequence、onEnum(of:))。Swift パッケージとして提供され、実機用 (ios-arm64) と Apple Silicon Mac のシミュレーター用 (ios-arm64-simulator) の静的 XCFramework です。
  • Android と JVM はまだ公開されていません (M6 の第 2 段階で Maven Central)。ソースからビルドしてください。

インストール

iOS: Swift Package Manager

iOS のライブラリは Swift パッケージです。リポジトリのルートにある Package.swift が、各 GitHub Release に添付された静的な Teslable.xcframework を指しているため、パッケージの URL はリポジトリの URL と同じです。

  1. Xcode で File > Add Package Dependencies… を選び、https://github.com/smallmiro/tesla-ble-kmp を入力します。
  2. 依存ルールに 1.0.0 からの Up to Next Major Version を選び、アプリのターゲットにプロダクト Teslable を追加します。
  3. Swift のコードに import Teslable と書きます。

Package.swift では次の 2 行を使います。

.package(url: "https://github.com/smallmiro/tesla-ble-kmp", from: "1.0.0")
// ターゲットの dependencies に追加:
.product(name: "Teslable", package: "tesla-ble-kmp")
  • 要件: iOS 16 以降と、Info.plist の NSBluetoothAlwaysUsageDescription。フレームワークは静的です。
  • シミュレーター: Apple Silicon Mac のみ。Release ビルドのようにすべてのアーキテクチャをビルドするシミュレーター向けビルドには EXCLUDED_ARCHS[sdk=iphonesimulator*] = x86_64 が必要です。17. プラットフォームノートを参照してください。
  • バージョンはセマンティックバージョニングに従います。公開 API を壊すリリースは新しいメジャーバージョンになるため、Up to Next Major Version は互換性のあるリリースだけを取り込みます。
  • CocoaPods はサポートしません。 CocoaPods trunk は 2026-12-02 から読み取り専用になります。

手順の詳細と完全なパッケージマニフェスト: 12. ライブラリ入門。

ソースからビルド (Android、JVM、コントリビューター)

Android と JVM はまだ公開されていません。開発は完了していますが、実際の Android 端末での確認が終わっておらず、Maven Central は M6 の第 2 段階で提供します。それまでは、このリポジトリの Gradle ビルドの中でビルドしてください (12. ライブラリ入門):

ターゲットコマンド
Android / JVM./gradlew :sdk:assemble
iOS シミュレーター用フレームワーク (ライブラリとサンプルアプリの開発用)./gradlew :sdk:linkDebugFrameworkIosSimulatorArm64
サンプルアプリsamples/android (Gradle モジュール)、samples/ios (xcodegen generate、samples/ios/README.md を参照)
実車での確認は保留中

バージョン 1.0.0 には、FakeVehicle のテストには通っていますが、まだ実車で確認していない機能が含まれています。特にインフォテインメントのコマンドと getState() です (チェックリスト: issue #118)。Android はまだ実機で確認していません。各領域の状態は現在できることの表にあります。
