# 클러스터 차량 사진 (SFR-022, SFR-024 변경) Implementation Plan

> 요청 2026-11-04. 사용자와 채팅으로 정한 작은 변경(brainstorming, 크기: small change). 사진은 사용자가 직접 만든 것이며 공개 저장소에 커밋해도 된다고 확인했다.

## 목표
iOS 샘플 Live 클러스터의 차량 그림을 사용자가 만든 사진 두 장으로 바꾼다.

- 탭 배치(일반 iPhone, Duo 접은 화면): `images/top.png` (1024x1536, 위에서 본 차, 앞이 위)
- 두 영역 배치(Duo 펼친 화면, iPad 포함, 기준은 기존 `DuoLayout` 규칙 그대로): `images/side.png` (1536x1024, 앞 왼쪽에서 비스듬히 본 차, 앞이 왼쪽 아래, 뒤가 오른쪽 위)

## 사용자 결정
- 열림 상태는 **아이콘으로 표시만** 한다. 문이 돌아가는 애니메이션과 부위 그림 겹치기는 없앤다.
- 두 영역 배치는 공식 Tesla 앱 화면 방식(사용자가 보여 준 참고 화면):
  - 사진 위 가운데 잠금 아이콘 + 아래로 세로선. 닫힌/열린 자물쇠로 상태 표시, 누르면 잠금/해제(기존 동작).
  - 왼쪽 위 두 줄 글자 "열기"(작은 회색) / "전면"(굵게) + 세로선이 차 앞(보닛)을 가리킴. 누르면 기존 프렁크 확인 창.
  - 오른쪽 위 "열기·닫기" / "트렁크" + 세로선이 차 뒤를 가리킴. 기존 트렁크 열기/닫기 동작.
  - 차 뒤 옆에 충전구 번개 아이콘 + 짧은 가로선. 열리면 빨강, 아니면 회색. 누를 수 없음.
  - 아래 동작 줄(깨우기, 트렁크 닫기)은 그대로.

## Claude 판단 (사용자에게 알림)
- 열린 문에만 빨간 문 아이콘을 짧은 선과 함께 그 문 위치 옆에 띄운다. `top.png` 도 같은 원칙(열린 부위만 빨간 아이콘, 말풍선 없음). 상태 모름은 아이콘 없이 기존 요약 글자로.
- 아이콘 위치는 사진별 정규화 좌표 표로 둔다(시험 대상).
- 기존 부위 SVG 7개 + 바탕(`ClusterCar*`)은 지운다.
- 사진 용량을 줄인다(두 장 3.4MB). 눈에 띄는 화질 저하 없이.
- 밝은 모드에서 사진의 검은 바탕 처리는 시뮬레이터로 보고 정한다.
- 실차 확인 빌드이므로 `CURRENT_PROJECT_VERSION` 을 23으로 올린다.
