tesla-ble-kmp Sample Apps

These pages describe the two sample apps in samples/: samples/android (Jetpack Compose) and samples/ios (SwiftUI). The samples are tools for checking, monitoring and exploring the library on a real car. They are not products.

On this page
  1. What the samples are for
  2. Pages
  3. How these pages are kept up to date

What the samples are for

The samples use the library the way a developer meeting it for the first time would: they follow only the library manual (chapters 11 to 19 of the developer manual). When the manual is missing something, the fix goes into the manual or the library, never into a workaround in the sample. This way the samples also test the manual.

Instructions for coding agents

Agents working on the samples read samples/AGENTS.md first, then samples/android/AGENTS.md or samples/ios/AGENTS.md. The Markdown version of these pages is in samples/documents/md/.

A pull request that changes what a sample does updates the Markdown page for agents (English) and these HTML pages in Korean, English and Japanese in the same pull request.
