15. 명령

Vehicle은 세션을 시작하고 끝낼 수 있으며, 보안 컨트롤러 명령 12가지(잠금, 트렁크, 깨우기)를 보낼 수 있습니다. 인포테인먼트 명령(공조, 충전, 미디어 등)은 M5에서 추가됩니다. 이 페이지에 둘 다 정리합니다.

이 페이지의 내용
  1. 현재 사용 가능
  2. 모든 명령의 공통 동작
  3. 보안 컨트롤러(M4)
  4. M5 예정: 인포테인먼트
  5. 이후 계획

현재 사용 가능

호출동작
startSession(domains, timeout)VCSEC와 Infotainment(기본값은 둘 다)의 핸드셰이크를 병렬로 실행합니다. 세션 캐시에서 이미 복원된 도메인은 차량에 묻지 않고 성공합니다. 등록된 키가 필요합니다. 기본 시간 제한 20초
disconnect()세션 캐시를 저장하고, 세션 키를 지우고, 링크를 닫습니다. 여러 번 호출해도 안전합니다

startSession이 실행되는 동안 vehicle.sessions는 Handshaking을 보여 주고, 끝나면 Ready, 실패하거나 취소되면 다시 None이 됩니다.

모든 명령의 공통 동작

  • 명령은 도메인 세션 위에서 AES-GCM으로 암호화, 인증되며 5초 후 만료됩니다.
  • 일시적 실패는 1초마다 자동으로 재시도합니다. 이미 실행되었을 수 있는 명령은 절대 다시 보내지 않습니다.
  • 보안 컨트롤러 명령은 연결마다 한 번에 하나씩 실행되고, 인포테인먼트 명령은 동시에 실행될 수 있습니다.
  • Uncertain 결과는 상태를 읽고 재전송하지 말라는 뜻입니다. 16. 에러 처리를 참고하세요.

보안 컨트롤러(M4)

12개 메서드는 모두 인증이 필요하고 VCSEC 세션이 있어야 합니다. 세션이 없으면 Failure(NoSession)을 돌려주므로 먼저 startSession(setOf(VehicleDomain.VCSEC))를 실행하세요. 각 메서드는 선택 인자 timeout(기본 5초)을 받고 VehicleResult<Unit>을 반환합니다.

키 등록과 제거FR-022–027참고: 13. 키와 페어링
  • 예상되는 실패: NoSession, NotConnected, InsufficientPrivileges(예: Vehicle Monitor 키이거나 차량 상태가 허용하지 않는 경우), VcsecRejected, UnknownVcsecError.
  • Uncertain은 차량이 실행했을 수 있다는 뜻입니다. 다시 보내지 말고 vehicleStatus()로 잠금 상태와 개폐부를 읽으세요. 토글인 openTrunk(), actuateTrunk()에서 특히 중요합니다. 16. 에러 처리를 참고하세요.
  • sessions는 실제 세션 상태를 따릅니다. 명령이 NoSession으로 끝나거나 세션 이벤트가 오면 라이브러리가 그 도메인을 다시 확인합니다. 차량이 더 이상 받아 주지 않는 캐시 세션(예: 다른 키의 캐시)은 첫 명령이 실패한 뒤 None으로 표시되며, startSession으로 복구합니다.
