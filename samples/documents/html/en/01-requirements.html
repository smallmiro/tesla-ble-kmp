1. Requirements

Sample requirements have their own IDs, SFR-xxx, so they never mix with the library's FR-xxx and NFR-xxx. They moved here from the library PRD on 2026-10-24. The PRD now covers only the library.

Rules for adding a requirement

  • A new requirement takes the next free SFR- number. The monitoring app planned in docs/superpowers/specs/2026-10-24-vehicle-events-monitor-design.md starts at SFR-010.
  • If a requirement needs a library feature that the library manual does not list as available, write it here with the status "waits for library" and raise the request with the library-api-request skill (see 2. Constraints).
  • Status words: planned, in progress, done, waits for library, waits for M5.
