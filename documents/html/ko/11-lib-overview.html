11. 라이브러리 개요

tesla-ble-kmp는 이 저장소에서 만드는 라이브러리로, vehicle-command의 BLE 경로를 Kotlin Multiplatform으로 포팅해 Android나 iOS 앱이 서버 없이 테슬라 차량과 직접 통신하게 합니다. 11장부터 19장까지는 이 라이브러리의 사용법을 설명합니다. 1장부터 9장까지는 Go 원본을 설명합니다.

예정된 API는 아직 사용할 수 없습니다

예정된 메서드의 이름은 요구사항 문서(docs/prd/PRD.md)에서 가져온 것이며 마일스톤이 반영될 때 바뀔 수 있습니다. 그때까지 앱은 스캔, 연결, 상태 읽기, 차량 브로드캐스트 수신, 키 등록, VCSEC 제어 명령 전송을 할 수 있지만 인포테인먼트 명령은 보낼 수 없습니다. 페어링과 VCSEC 명령은 아직 실차에서 확인하지 않았습니다.

플랫폼과 패키지

  • Android 12(API 31) 이상, iOS 16 이상을 지원합니다. 앱은 포그라운드에 있다고 가정합니다.
  • 테스트와 실험용 JVM 타깃이 있습니다. 이 타깃의 키와 세션 캐시는 메모리에만 존재합니다.
  • 패키지 루트는 dev.mirolab.teslable입니다. 파사드는 dev.mirolab.teslable, 값과 결과는 dev.mirolab.teslable.model, 키 보관소와 스캔, 로깅은 dev.mirolab.teslable.port에 있습니다.
  • iOS 프레임워크 이름은 Teslable입니다. Swift는 SKIE를 통해 Kotlin을 봅니다(async 함수, AsyncSequence, onEnum(of:)).

설치

라이브러리는 아직 배포되지 않았습니다. M6에서 GitHub Packages와 Swift Package Manager 배포가 추가됩니다. 지금은 소스에서 빌드하세요.

이 페이지들을 최신으로 유지하는 방법
