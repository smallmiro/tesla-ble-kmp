tesla-ble-kmp サンプルアプリ

これらのページでは、samples/ にある 2 つのサンプルアプリを説明します。samples/android（Jetpack Compose）と samples/ios（SwiftUI）です。サンプルは、実車でライブラリを確認・監視・調査するためのツールであり、製品ではありません。

  2. ページ一覧
  3. これらのページの更新方法

サンプルの目的

サンプルは、初めてライブラリに触れる開発者と同じ立場でライブラリを使います。参照するのはライブラリマニュアル（開発マニュアルの第 11 章から第 19 章）だけです。マニュアルに足りないものがあれば、サンプル側で回避せず、マニュアルかライブラリを直します。こうすることで、サンプルはマニュアルのテストにもなります。

コーディングエージェント向けの案内

サンプルを扱うエージェントは、まず samples/AGENTS.md を読み、次に samples/android/AGENTS.md または samples/ios/AGENTS.md を読みます。これらのページの Markdown 版は samples/documents/md/ にあります。

これらのページの更新方法

サンプルの動作を変更するプルリクエストでは、同じプルリクエストの中で、エージェント向けの Markdown ページ（英語）と、これらの HTML ページ（韓国語・英語・日本語）を更新します。
