11. ライブラリ概要

tesla-ble-kmp はこのリポジトリで作っているライブラリです。vehicle-command の BLE 経路を Kotlin Multiplatform に移植したもので、Android や iOS のアプリがサーバーなしでテスラと直接通信できるようにします。第 11 章から第 19 章ではその使い方を、第 1 章から第 9 章では Go の原本を説明します。

予定中の API はまだ使えません

予定中のメソッド名は要件文書 (docs/prd/PRD.md) に基づくもので、そのマイルストーンの実装時に変わる可能性があります。それまでの間、アプリはスキャン、接続、状態の読み取りはできますが、キーの登録や制御コマンドの送信はできません。

プラットフォームとパッケージ

  • Android 12 (API 31) 以降と iOS 16 以降に対応します。アプリはフォアグラウンドにあることを前提とします。
  • テストや実験用に JVM ターゲットもあります。そのキーとセッションキャッシュはメモリ上にのみ保持されます。
  • パッケージのルートは dev.mirolab.teslable です。ファサードは dev.mirolab.teslable、値と結果は dev.mirolab.teslable.model、キーストア、スキャン、ログは dev.mirolab.teslable.port にあります。
  • iOS フレームワーク名は Teslable です。Swift からは SKIE を通して Kotlin が見えます (async 関数、AsyncSequence、onEnum(of:))。

インストール

ライブラリはまだ公開されていません。M6 で GitHub Packages と Swift Package Manager に対応します。現時点ではソースからビルドしてください:

ターゲットコマンド
Android / JVM./gradlew :sdk:assemble
iOS シミュレーター用フレームワーク./gradlew :sdk:linkDebugFrameworkIosSimulatorArm64
サンプルアプリsamples/android (Gradle モジュール)、samples/ios (xcodegen generate、samples/ios/README.md を参照)

これらのページの更新方法

ライブラリの動作、公開 API、マイルストーンの状態を変えるプルリクエストは、マージ前に必ずこれらのページを更新します。対象はエージェント向けの Markdown ページ (documents/md/1x-lib-*.md、英語) と、人向けの韓国語、英語、日本語の HTML ページです。Go リファレンスの第 1 章から第 9 章は、メンテナーの承認がある場合にのみ変更します。
