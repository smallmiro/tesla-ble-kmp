How to read the tables

ColumnMeaning
CLItesla-control command and positional arguments. Square brackets denote optional arguments. "—" means there is no CLI command
Go(*vehicle.Vehicle) method. The first argument, ctx, is omitted
ProxyThe <name> in POST /api/1/vehicles/{VIN}/command/<name> and the JSON body keys. Based on pkg/proxy/command.go. "—" means there is no proxy endpoint (it is not forwarded to REST either and yields invalid_command)
DomainVCSEC Security controller. Responds over BLE even while Infotainment is asleep. INFO Infotainment. Must be woken first if asleep
AuthRequired Requires a private key and a session (requiresAuth). Not required Can be sent without a session
NotesBLE only, Fleet API only, model restrictions, etc.
Role restrictions

Even the same command may be rejected depending on the key's role (MESSAGEFAULT_ERROR_INSUFFICIENT_PRIVILEGES). For example: Driver cannot manage keys or change PINs, Vehicle Monitor can only query state, Charging Manager can only use charging-related commands, and Fleet Manager on 2023.38+ cannot send BLE commands or add/remove other keys. For details on roles, see 4. Protocol Specification.

Endpoints the proxy passes to REST

The following command/ endpoints require server-side processing and cannot be implemented with end-to-end authentication. When the proxy encounters ErrCommandUseRESTAPI, it forwards the original request to the Fleet API unchanged.

  • navigation_request
  • set_managed_charge_current_request
  • set_managed_charger_location
  • set_managed_scheduled_charging_time

All paths other than command/ (query endpoints such as vehicle_data, other than wake_up, etc.) are always forwarded. If the vehicle does not support this protocol and the Fleet API returns 422, that VIN is always forwarded from then on (8. HTTP Proxy).
