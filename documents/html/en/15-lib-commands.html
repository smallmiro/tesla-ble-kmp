15. Commands

A Vehicle can start and end sessions and send the twelve security-controller commands (locks, trunks, wake-up). Infotainment commands (climate, charging, media and more) arrive with M5. This page lists both.

Available today

CallWhat it does
startSession(domains, timeout)Runs the handshake for VCSEC and Infotainment (both by default) in parallel. A domain already restored from the session cache succeeds without asking the car. Needs a key that is enrolled. If the phone lock blocks the key (an iOS Secure Enclave key that only works unlocked), it fails as soon as the car answers with KeyStoreError.Locked and is not retried (13). Default timeout 20 seconds
disconnect()Saves the session cache, erases session keys and closes the link. Safe to call more than once

While startSession runs, vehicle.sessions shows Handshaking; afterwards Ready, or None again if it failed or was cancelled.

How every command behaves

  • Commands are encrypted and authenticated with AES-GCM over the domain's session and expire after 5 seconds.
  • Temporary failures are retried every second automatically. A command that may already have run is never sent again.
  • Security-controller commands run one at a time per connection; infotainment commands may run side by side.
  • An Uncertain result means: read the state, do not resend. See 16. Error Handling.

Security controller (M4)

All twelve methods are authenticated and need a VCSEC session; without one they return Failure(NoSession), so run startSession(setOf(VehicleDomain.VCSEC)) first. Each takes an optional timeout (default 5 seconds) and returns VehicleResult<Unit>.

  • Likely failures: NoSession, NotConnected, InsufficientPrivileges (for example a Vehicle Monitor key, or the car state forbids it), VcsecRejected, UnknownVcsecError.
  • Uncertain means the car may have acted. Do not resend; read vehicleStatus() for the lock state and closures. This matters most for the toggles openTrunk() and actuateTrunk(). See 16. Error Handling.
  • sessions follows the real session state. When a command ends with NoSession, or a session event arrives, the library re-checks that domain. A cached session the car no longer accepts (for example the cache belonged to another key) shows None after the first command fails; startSession recovers it.

Later

Planned for v1.1: HomeLink, clearing PIN to Drive, speed limit mode, parental controls, guest mode, renaming the car and nearby chargers. Setting PIN to Drive is not possible over BLE and is left out. The Go equivalents of every command are listed in 7. Command Reference.
