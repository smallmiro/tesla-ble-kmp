12. Getting Started with the Library

Walks through the whole M3 flow: create the library, get a key, find the car, connect, read its state and disconnect. Key enrollment arrives in M4, so for now the examples use only queries that do not need an enrolled key.

On this page
  1. The flow
  2. Five rules
  3. Kotlin (Android)
  4. Swift (iOS)
  5. Next steps

The flow

  1. Create the library. TeslaBle.create(platform, config), once per app.
  2. Get a key. ble.keys.getOrCreate() returns the phone's P-256 key, creating it in the secure hardware the first time.
  3. Find the car. ble.scan(vin) emits the car's advertisements; take the first one.
  4. Connect. ble.connect(vin, key, advertisement) returns a Vehicle.
  5. Read. vehicleStatus(), keySummary(), listKeys().
  6. Clean up. vehicle.disconnect(), then ble.close() when the app is done.

Five rules

  • Results are values. Every call to the car or the key store returns a VehicleResult: Success, Uncertain or Failure. Nothing is thrown, except when your own coroutine is cancelled.
  • One TeslaBle per app. Call close() when you are done; it also disconnects any car still connected.
  • Always disconnect. Call vehicle.disconnect() even if the link already dropped. It saves the session cache, erases session keys and frees the car's BLE slot. Calling it twice is fine.
  • A key is optional for reading. connect(vin, key = null) is enough for the three queries; starting a session needs a key.
  • Debug logging only in development. DebugLogger() writes to the platform log; leave it out of release builds.

Kotlin (Android)

import dev.mirolab.teslable.*
import dev.mirolab.teslable.model.*
import dev.mirolab.teslable.port.*
import kotlinx.coroutines.flow.first

suspend fun demo(context: android.content.Context, vinText: String) {
    val vin = Vin.parseOrNull(vinText) ?: return              // 17-character format check
    val ble = TeslaBle.create(
        PlatformContext(context),
        TeslaBleConfig.default(logger = DebugLogger()),         // development logger, not for release builds
    )
    try {
        val key = when (val r = ble.keys.getOrCreate()) {       // default alias, hardware first
            is VehicleResult.Success -> r.value
            is VehicleResult.Uncertain -> return
            is VehicleResult.Failure -> return                  // r.error: KeyStoreError
        }

        // Take the first advertisement. The caller sets the time limit (for example withTimeoutOrNull).
        val event = ble.scan(vin).first()
        val target = (event as? ScanEvent.Found)?.advertisement ?: return   // on Failed, see event.error

        val vehicle = when (val r = ble.connect(vin, key, target)) {
            is VehicleResult.Success -> r.value
            is VehicleResult.Uncertain -> return
            is VehicleResult.Failure -> return                  // r.error: TransportError and others
        }
        try {
            println(vehicle.vehicleStatus())                    // show it in the UI instead of println
            println(vehicle.listKeys())
        } finally {
            vehicle.disconnect()                                // frees the slot; call it even after the link dropped
        }
    } finally {
        ble.close()                                             // suspend; disconnects any vehicle still connected
    }
}

Request BLUETOOTH_SCAN and BLUETOOTH_CONNECT at runtime before these calls. See Platform Notes.

Swift (iOS)

SKIE turns suspend functions into async throws, Flow into AsyncSequence, and lets switch onEnum(of:) cover every case of a result. The code has the same shape as samples/ios/Sources/SampleModel.swift.

import Teslable

let ble = TeslaBle.companion.create(
    platform: PlatformContext(),
    config: TeslaBleConfig.companion.default(logger: DebugLogger())
)

func run(vinText: String) async {
    guard let vin = Vin.companion.parseOrNull(value: vinText) else { return }   // bad format

    // 1) Key
    var key: VehicleKey?
    do {
        let result = try await ble.keys.getOrCreate(alias: VehicleKeyStoreCompanion.shared.DEFAULT_ALIAS, policy: .preferHardware)
        switch onEnum(of: result) {
        case .success(let s): key = s.value as? VehicleKey
        case .uncertain(let u): print("uncertain: \(u.error.message)")
        case .failure(let f): print("failure: \(f.error.message)")
        }
    } catch { print("error: \(error)") }

    // 2) Scan (stop at the first advertisement; set a time limit by cancelling the Task)
    for await event in ble.scan(vin: vin) {
        switch onEnum(of: event) {
        case .found(let f): print("\(f.advertisement.localName.value) rssi=\(f.advertisement.rssi)")
        case .failed(let e): print("scan failed: \(e.error.message)")
        }
        break
    }

    // 3) Connect and query
    do {
        let connected = try await ble.connect(vin: vin, key: key, target: nil, options: ConnectOptions(timeout: nil))
        switch onEnum(of: connected) {
        case .success(let s):
            guard let vehicle = s.value as? Vehicle else { return }
            let status = try await vehicle.vehicleStatus(timeout: nil)
            switch onEnum(of: status) {
            case .success(let v): print("status: \(String(describing: v.value))")
            case .uncertain(let u): print("uncertain: \(u.error.message)")   // query again, do not resend
            case .failure(let f): print("failure: \(f.error.message)")
            }
            try await vehicle.disconnect()
        case .uncertain(let u): print("uncertain: \(u.error.message)")
        case .failure(let f): print("failure: \(f.error.message)")
        }
    } catch { print("error: \(error)") }
}

With target: nil, connect scans by itself. Add NSBluetoothAlwaysUsageDescription to Info.plist; see Platform Notes.

Next steps

  • Enrolling the key on the car comes in M4 (13. Keys and Pairing). Until then, connect(vin, key = null) is enough for vehicleStatus(), keySummary() and listKeys().
  • Watch the link with vehicle.connection and the sessions with vehicle.sessions, both StateFlows. When the link reports Disconnected, still call disconnect() yourself.
