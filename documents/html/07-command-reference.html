표 읽는 법

열의미
CLItesla-control 명령과 위치 인자. 대괄호는 선택 인자. "—"는 CLI 명령이 없음
Go(*vehicle.Vehicle) 메서드. 첫 인자 ctx는 생략
프록시POST /api/1/vehicles/{VIN}/command/<이름>의 <이름>과 JSON 본문 키. pkg/proxy/command.go 기준. "—"는 프록시 엔드포인트가 없음(REST로도 전달되지 않고 invalid_command)
도메인VCSEC 보안 컨트롤러. Infotainment가 잠들어 있어도 BLE로 응답. INFO Infotainment. 잠들어 있으면 먼저 깨워야 함
인증필요 개인 키와 세션 필요(requiresAuth). 불필요 세션 없이 전송 가능
비고BLE 전용, Fleet API 전용, 차종 제한 등
역할 제한

같은 명령이라도 키의 역할에 따라 거부될 수 있습니다(MESSAGEFAULT_ERROR_INSUFFICIENT_PRIVILEGES). 예: Driver는 키 관리와 PIN 변경 불가, Vehicle Monitor는 상태 조회만, Charging Manager는 충전 관련만, Fleet Manager는 2023.38+에서 BLE 명령과 다른 키 추가/삭제 불가. 자세한 역할 설명은 4. 프로토콜 사양을 보세요.

프록시가 REST로 넘기는 엔드포인트

다음 command/ 엔드포인트는 서버 측 처리가 필요해 종단 간 인증으로 구현할 수 없습니다. 프록시는 ErrCommandUseRESTAPI를 만나면 원래 요청을 Fleet API로 그대로 전달합니다.

  • navigation_request
  • set_managed_charge_current_request
  • set_managed_charger_location
  • set_managed_scheduled_charging_time

command/가 아닌 모든 경로(vehicle_data, wake_up이 아닌 조회 엔드포인트 등)는 항상 포워딩됩니다. 차량이 이 프로토콜을 지원하지 않아 Fleet API가 422를 돌려주면 그 VIN은 이후 항상 포워딩됩니다(8. HTTP 프록시).
