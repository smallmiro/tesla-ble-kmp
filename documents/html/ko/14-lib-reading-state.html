14. 차량 상태 조회

세 가지 조회는 BLE로 차량의 보안 컨트롤러(VCSEC)를 읽습니다. 인포테인먼트 컴퓨터가 잠들어 있어도 VCSEC는 응답하므로, 키도 세션도 깨우기도 필요 없습니다.

이 페이지의 내용
  1. 세 가지 조회
  2. vehicleStatus()가 반환하는 값
  3. 키 조회가 반환하는 값
  4. 연결 상태와 세션 상태
  5. 절전과 깨우기

세 가지 조회

호출반환Go 원본
vehicleStatus()잠금, 문, 트렁크, 충전 포트, 절전 상태, 탑승자 감지BodyControllerState
keySummary()등록된 키 개수와 사용 중인 슬롯KeySummary
listKeys()등록된 모든 키와 각 키의 공개키, 역할, 폼 팩터KeySummary + KeyInfoBySlot
  • 각 조회는 선택 인자 timeout을 받습니다. 지정하지 않으면 기본 명령 시간 제한(5초)이 적용됩니다. listKeys()의 시간 제한은 내부 요청 전체에 함께 적용됩니다.
  • 차량은 연결마다 VCSEC 요청을 한 번에 하나씩 처리합니다. 다른 조회를 기다려야 하는 조회는 시간 제한의 일부를 대기에 씁니다.
  • 이들은 조회이므로 Uncertain 결과가 나오면 그냥 다시 조회하면 됩니다.

vehicleStatus()가 반환하는 값

필드값
lockStateUNLOCKED, LOCKED, INTERNAL_LOCKED, SELECTIVE_UNLOCKED, UNKNOWN
closures여덟 개 개폐부, 각각 ClosureState. 차량이 보내지 않으면 모두 CLOSED (모두 닫히면 차량이 생략하며, Go getter와 같음)
sleepStatusAWAKE, ASLEEP, UNKNOWN
userPresencePRESENT, NOT_PRESENT, UNKNOWN
tonneauPercentOpenCybertruck 전용, 그 외에는 null

여덟 개 개폐부는 frontDriverDoor, frontPassengerDoor, rearDriverDoor, rearPassengerDoor, rearTrunk, frontTrunk, chargePort, tonneau입니다. 각각 CLOSED, OPEN, AJAR, OPENING, CLOSING, FAILED_UNLATCH, UNKNOWN 중 하나입니다.

알 수 없는 값은 실패로 처리하지 않습니다

새 차량 펌웨어가 라이브러리가 아직 모르는 값을 보내면, 조회를 실패시키지 않고 해당 필드를 UNKNOWN으로 읽습니다.

키 조회가 반환하는 값

타입필드의미
WhitelistSummarynumberOfEntries등록된 키 개수
slotMask, occupiedSlots사용 중인 슬롯, 비트 마스크와 정렬된 목록
WhitelistEntryslot슬롯 번호
publicKey65바이트 공개키, 없거나 형식이 잘못되면 null
keyIdSha1Hex공개키의 SHA-1 16진수 값, 또는 null
role, formFactor예: OWNER, IOS_DEVICE. 13. 키와 페어링 참고

연결 상태와 세션 상태

다음은 차량에 보내는 질의가 아니라 관찰하는 Vehicle의 속성입니다.

속성값
connectionConnected, 또는 Disconnected(알려진 경우 이유 포함)
sessionsVCSEC와 INFOTAINMENT 각각: None, Handshaking, Ready(fromCache 포함)
hasKey키를 사용해 연결했는지 여부
vinVIN. 출력하면 마스킹된 형태가 나옵니다. vin.value는 원본 VIN이므로 로그에 남기면 안 됩니다

절전과 깨우기

  • 세 가지 조회 모두 차량을 깨우지 않습니다. 잠들어 있는지 보여 주려면 sleepStatus를 사용하세요.
  • M5 예정: getState(category)는 인포테인먼트의 12개 카테고리(충전, 공조, 주행, 위치, 개폐부, 충전 일정, 사전 공조 일정, 타이어 공기압, 미디어, 미디어 상세, 소프트웨어 업데이트, 자녀 보호)를 읽습니다. 등록된 키와 깨어 있는 차량이 필요합니다.
  • M4 예정: wakeUp(). VCSEC 세션만 있으면 됩니다.
  • 잠금이나 트렁크 명령(M4)이 Uncertain으로 돌아오면, 명령을 다시 보내지 말고 vehicleStatus()를 다시 읽으세요.
